# Lodestar screen generator

The design boards in `Designing/pages/P1–P6` are the source of truth for every screen. This tool turns them into app code, so the website and the mobile app look and click through exactly like the Figma prototype.

| Design frames | Becomes | Where |
|---|---|---|
| Desktop (1440 × 900): Lodestar Store desk, Lodestar Plan, Lodestar Admin, dead-zone and reefer desk screens | Next.js pages using the design's own CSS | `frontend/app/<store\|plan\|admin>/<screen>/`, `frontend/screens/` |
| Phone (390 × 844) and Dock tablet (1024 × 768) | Native React Native views (`View`/`Text`/SVG) | `mobile/src/screens/`, opened at `/s/<screen>` |

How it works:

- `extract.js` opens each board in Chrome and reads every frame exactly as Chrome lays it out.
  - Desktop frames become JSX markup.
  - Phone and tablet frames become a flexbox tree built from computed styles. The boards use flexbox only, so this maps 1:1 onto React Native.
- **Links:** these come from `Designing/figma-plugin/data/links.json`, the same data that wires the Figma prototype.
  - Buttons are found with the same matching rules as the Figma plugin (`hotspots.js`).
  - Tab bars and sidebars follow the nav map.
  - Back arrows and ✕ icons return to the screen that opened them.
  - "Agent drafting" and "Sync queue" advance by themselves after 1.5 s.
- **Read aloud:** these controls speak the screen on the device with `expo-speech`. Sinhala and Tamil text uses the matching voice.
- **Cross-device steps:** a step that continues on another device (for example Plan desktop to Dock phone) shows a short notice instead of navigating.

## Run

```bash
cd tools/screengen
npm install                 # puppeteer-core; uses the Chrome already installed (set CHROME=... if elsewhere)
npm run screens             # extract + website + mobile
```

Generated files start with `// Generated by tools/screengen`. Don't edit them by hand: change the board HTML and run the generator again.

To check fidelity, run the website (`npx next start -p 3100` in `frontend/`) or the app's web preview (`npx expo start --web` in `mobile/`), then:

```bash
npm run compare:web         # side-by-side PNGs + pixel difference, out/cmp-web/
npm run compare:mobile      # out/cmp-mobile/
```
